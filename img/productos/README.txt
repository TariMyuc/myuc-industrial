fondo blanco o gris niebla (#F2F3F4), producto centrado con 10 % de aire, sin textos ni logos.

Cómo subir desde GitHub (sin tocar código):

  2. Add file → Upload files → arrastra las fotos → Commit changes
  3. Netlify publica solo en un minuto.
